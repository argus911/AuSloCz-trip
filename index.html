注意事項

機上過夜
建議穿舒適寬鬆衣物與好走鞋，並攜帶口罩、眼罩、空水瓶與保暖外套。
特殊需求
若需特殊餐食或一大床房型，應於報名時提前告知，以利安排。
隨團配備
行程含導覽耳機、行李束帶、歐規轉接插頭，以及每人一張 20G 流量網卡。
天候備案
國王湖遊船受天候影響大，若無法乘船，現場退費每人 15 歐元；鹽礦若遇維修，將改往哈萊茵鹽礦。

發布到 iPhone 主畫面

1. 將這個檔案命名為 index.html 放在 GitHub Pages 專案根目錄。
2. 用 iPhone 的 Safari 開啟 GitHub Pages 網址，點分享 →「加入主畫面」。
3. 主畫面會顯示名稱「奧捷12天」與你準備的 App 圖示。
若要再調整實際班機時間或內容，只要改上方「航班資訊」或下方 script 裡的 days 陣列即可，其他程式不用動。[file:50]
